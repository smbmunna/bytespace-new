# ByteSpace New

A modern educational platform landing page built with Next.js, TypeScript, and Tailwind CSS, developed from Figma specifications.

## Live Demo & Repository
* **Live Deployment:** https://bytespace-new-eosin.vercel.app/
* **GitHub Repository:** https://github.com/smbmunna/bytespace-new.git

## Tech Stack
* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Animation:** Framer Motion / Tailwind CSS Keyframes

## Getting Started Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/smbmunna/bytespace-new.git
   cd bytespace-new
   ```

2. Install dependencies:
   ```bash
   npm install  
   ```
3. Run the Development Server:   
   ```bash
   npm run dev
   ```
4. Open http://localhost:3000 in your browser.
